# ASCII Sharks Studio

A browser studio for turning live ASCII sharks into wallpapers — live (Wallpaper Engine, Lively, any browser), video loops, stills and more, sized for desktop and phone.

**Open it:** the GitHub Pages site for this repository.

Everything runs locally in your browser. No accounts, no tracking, no uploads; settings are kept only in your own browser's local storage.
